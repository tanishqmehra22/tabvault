# TabVault — Smart Browser Tab Manager

**Live demo & download:** https://tabvault-six.vercel.app · **Source:** https://github.com/tanishqmehra22/tabvault

A local-first Chrome extension (Manifest V3, vanilla HTML/CSS/JS) for saving tabs, organizing them into collections, and saving/restoring whole browsing sessions. Nothing leaves your machine: no backend, no sync, no analytics, no remote code or fonts.

## Install (unpacked)

1. Open `chrome://extensions` in Chrome (version 120 or newer).
2. Turn on **Developer mode** (top-right).
3. Click **Load unpacked**.
4. Select the **`tabvault/extension`** folder — the one that directly contains `manifest.json`. (Not `tabvault/` itself.)
5. Pin TabVault from the puzzle-piece menu so the popup is one click away.

After editing code, click the reload icon on the extension's card in `chrome://extensions`.

## Features

| Area | What it does |
| --- | --- |
| **Popup** (380 px) | Shows open-tab count; **Save All Tabs** / **Save Current Tab** into a chosen collection; search open and saved tabs (`Ctrl/⌘ + K`); recent saves with favorite/delete; Restore Last Session; open the dashboard. |
| **Saved Tabs** | Search by title/URL/domain; filter by collection, domain, date; sort; favorites; grid/list view; multi-select to restore in a new window, move, or delete; Add URL; Export JSON. |
| **Collections** | Create, rename, delete (tabs fall back to Inbox), move tabs between collections, restore a whole collection in one window. Inbox is permanent. |
| **Sessions** | Save the current window under a name with timestamp + tab metadata, view tabs, restore in a new window, delete. |
| **Search & Duplicates** | Global search across tabs and sessions. Duplicates are detected after stripping tracking params (`utm_*`, `fbclid`, `gclid`, `dclid`, `msclkid`); cleanup keeps the newest copy, merges its favorite flag and collections, and always asks for confirmation. |
| **Settings** | Light / dark / system theme, default view and collection, skip-duplicate-saves, JSON import (validated, replaces vault after confirmation), JSON export, storage usage, erase vault (type `DELETE`). |

Only `http:` and `https:` pages are saved; `chrome://`, `file:`, `javascript:` and similar URLs are skipped. Dashboard shortcut: `/` focuses search.

## Permissions

| Permission | Why |
| --- | --- |
| `tabs` | Read titles/URLs of open tabs to save them and to restore saved tabs/sessions in a new window. |
| `storage` | `chrome.storage.local` holds your vault (`tabvault.v1`), plus `chrome.storage.session` for a short restore cooldown. |

No host permissions, no content scripts, no `downloads` (export uses a local file download from the page). The extension-page CSP is `script-src 'self'; connect-src 'none'`, so no network requests are possible.

## Architecture

```
extension/
  manifest.json
  popup.html, dashboard.html
  css/    theme.css (design tokens, light/dark) · popup.css · dashboard.css
  js/
    background.js   service worker; the only writer of the vault (serialized queue)
    storage.js      read/write, message client, change subscription
    settings.js     schema validation (whitelist), import/export, settings
    tabs.js · collections.js · sessions.js · search.js   pure logic
    ui.js           DOM helpers (text via textContent only), dialogs, toasts
    popup.js · dashboard.js
  assets/  icons (generated by tools/make-icons.mjs) · local Inter + Plus Jakarta Sans fonts
design-reference/   unpacked Google Stitch export (original ZIP kept untouched next to this folder)
tests/              logic.test.js · harness/ (dev-only browser harness)
```

All mutations go UI → `chrome.runtime.sendMessage` → `background.js` → `chrome.storage.local` as a single atomic snapshot, validated on every read and write. Tabs, collections and sessions use stable UUIDs.

## Testing

```bash
cd tabvault
npm test          # 14 automated logic tests (node:test, no dependencies)
npm run check     # syntax-check every extension script
npm install && npx playwright install chromium   # one-time, for the browser test
npm run test:browser   # loads the real extension in Chromium (HEADED=1 to watch)
```

The tests cover URL normalization, search/filter/sort, saving with dedupe, collection CRUD and Inbox fallback, sessions, duplicate cleanup, import validation (bad schema, bad URLs, missing collections, duplicate IDs, oversize, prototype keys), export→import round trip, settings, and the write queue.

**Real-extension browser test.** `tests/browser.mjs` launches Chromium with the unpacked extension and drives the actual popup, dashboard and service worker against local pages: manifest/permissions, save all with tracking-param dedupe, popup search, collections + move, favorites, session save and restore into a new window, restore cooldown, duplicate cleanup with confirmation, theme persistence, export/import round trip with invalid-file rejection, typed-confirm erase, and no uncaught page errors.

**Browser harness (dev only).** `npm run harness` serves `extension/` at `http://127.0.0.1:8765` with a stub `chrome.*` API for quick visual checks of `/popup.html` and `/dashboard.html`. Never ship `tests/`.

### Manual checklist in real Chrome
1. Load unpacked; confirm no errors on the extension card (click **service worker** to inspect).
2. Open several tabs including a `chrome://` page. Popup → **Save All Tabs**: toast reports saved/skipped counts; the `chrome://` tab is skipped.
3. Save the same URL again (also with `?utm_source=x`): reported as duplicate, not added twice.
4. Dashboard → create collection, move a tab, favorite, filter, switch grid/list, delete a tab.
5. Sessions → **Save current window**, close the window, **Restore**: all tabs reopen in one new window. Click Restore twice quickly: second is refused by the 4 s cooldown.
6. Settings → turn off *Skip duplicate saves*, save all again, then Search & Duplicates → clean (confirmation appears).
7. Export JSON, edit the file to break it, import: rejected with a message and nothing changes. Import the good file: confirm dialog, vault replaced.
8. Switch theme; close and reopen Chrome: theme and data persist.
9. Erase vault requires typing `DELETE`.

## Design
Follows the Stitch "TabVault Workspace System": dark navy surfaces (`#090d16` / `#0f172a` / `#1e293b`), sapphire/teal accents, Plus Jakarta Sans headings and Inter body, 380 px compact popup, 240 px dashboard sidebar. Stitch mock data that has no real backing (RAM saved, Pro badge, fake sync status, mobile companion, tags, analytics) is intentionally omitted. A light theme was added for the theme setting.

## Website & demo (Vercel)
`vercel.json` builds a static site: `node tools/build-site.mjs` assembles `site/` from `site-src/` (landing page), a live demo at `/demo/popup.html` and `/demo/dashboard.html` (the real extension pages with a stubbed `chrome.*` API and sample data, stored only in the visitor's browser), and `tabvault-extension.zip`. Import the repo at vercel.com/new and keep the defaults. Preview locally: `node tools/build-site.mjs && npx serve site`.
